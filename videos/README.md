# 動画置き場

ページ先頭のセクション01「まずは、動いているところを見てください」で再生するデモ動画を置くフォルダです。

## 置くファイル

| ファイル名 | 内容 |
| --- | --- |
| `demo.mp4` | リモコンでゲームを遊ぶ → 目標スコア達成 → ガチャのロックが解除 → 実際に回してカプセルが出てくるまで |

## 差し込み手順

1. 動画を `videos/demo.mp4` として置く
   - iPhoneで撮った `.mov` はブラウザによっては再生できないので、`.mp4`(H.264 + AAC)に変換しておくと確実:
     ```
     ffmpeg -i 元動画.mov -vcodec libx264 -acodec aac -movflags +faststart demo.mp4
     ```
   - 展示ブースでスマホから見る前提なので、**長くても1分程度**・**縦横どちらでも可**。
     ファイルサイズは 10〜20MB 以内が目安(それ以上だと読み込みが遅い)
2. `index.html` のセクション01にある `<figure class="photo-todo video-todo">` のブロックを削除する
3. そのすぐ下のコメントアウトされた `<div class="video-wrap">` のコメント記号(`<!--` と `-->`)を外す

## サムネイル(任意)

再生前に表示される静止画を出したい場合は `images/demo-poster.jpg` を置いて、
`<video>` タグに `poster="images/demo-poster.jpg"` を足す。

## 注意

- 動画に**来場者の顔が写り込んでいないか**を確認してから公開すること。
  遊んでいる様子を撮るなら、手元とガチャ機だけが入るアングルにするのが安全。
- 音が出るので `controls` は必須(自動再生はしない設定にしてあります)。
