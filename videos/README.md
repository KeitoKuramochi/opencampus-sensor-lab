# 動画置き場

ページ先頭のセクション01「まずは、動いているところを見てください」で再生するデモ動画を置くフォルダです。

## 現在入っているもの

| ファイル | 内容 |
| --- | --- |
| `demo.mp4` | 1280x720 / H.264 / 約52秒 / 約10MB。目標スコア選択 → プレイ → 151点で目標(100点)達成 → 「かいじょ!まわしてね」→ ハンドルを回す → カプセル排出 → 「ロック中」に戻るまで |

元データは iPhone の 4K/HEVC(3840x2160・317MB)で、リポジトリには入れていません。
`画像/opencampus素材/IMG_6539.MOV` に退避してあります。

## 差し替えるとき

```
ffmpeg -i 元動画.MOV -vf "scale=1280:-2" \
  -c:v libx264 -preset medium -crf 25 -pix_fmt yuv420p \
  -c:a aac -b:a 96k -movflags +faststart demo.mp4
```

- `-crf` は数字を大きくするほど低画質・小サイズ(23〜28あたりで調整)
- `-movflags +faststart` は必須。これが無いと、全部ダウンロードするまで再生が始まらない
- 展示ブースでスマホから見る前提なので、**10〜20MB以内**が目安

## サムネイル(任意)

再生前に表示される静止画を指定したい場合は、任意のフレームを書き出して
`images/demo-poster.jpg` として置き、`<video>` タグに `poster="images/demo-poster.jpg"` を足す。

```
ffmpeg -ss 40 -i demo.mp4 -frames:v 1 -q:v 3 ../images/demo-poster.jpg
```

指定しない場合は先頭フレームが表示されます。

## 注意

- **公開前に一度は通しで再生して確認すること。** 特に:
  - 来場者の顔や名札が写り込んでいないか
  - 音声に会話が入っていないか
- 音が出るので `controls` は必須(自動再生はしない設定にしてあります)。
