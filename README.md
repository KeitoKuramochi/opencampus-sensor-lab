# オープンキャンパス技術解説ページ

オープンキャンパスの展示ブース(100円ショップのLEDライトを分解してESP32でリズムゲーム化した工作)を、来場者向けに技術目線で解説する1ページのサイトです。QRコードから来場者がスマホで読める前提で作っています。

- 100円ショップの「300円センサー」を分解
- 赤外線受信部(VS838)とESP32の配線
- Arduino IDEのシリアルモニタで受信コードを確認する様子
- ESP32(マイコン)の説明
- 赤外線・WiFi・Bluetoothの使い分け
- スターターキットに入っている他のセンサー紹介ギャラリー
- 学科への誘導CTA・来場者アンケート

工作そのものの制作過程(配線・詰まったところ・全ソースコード)は別リポジトリで公開しています:
[sensor_infrared](https://github.com/KeitoKuramochi/sensor_infrared)

## 構成

素のHTML + CSS(フレームワークなし、ビルド不要)。`index.html` を開くだけで表示できます。

```
opencampus/
├── index.html
├── style.css
├── images/            使い回しの写真(分解写真・配線写真など)
│   └── sensors/        スターターキットの他パーツ紹介用の写真
└── README.md
```

## 公開

Vercel で公開しています。`main` への push で自動デプロイされます。
