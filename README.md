# センサー工作の技術解説ページ

100円ショップの300円リモコンライトを分解して赤外線センサーを取り出し、そこから
**マイコン2台とPCをつないで、ゲームで目標スコアを取るとガチャガチャのロックが開く**
仕組みを作るまでを、一連の技術記事としてまとめた1ページのサイトです。
展示ブースの前でスマホから読める前提で作っています。

15. (おまけ)まとめ

### 無線の構成について(記事の内容と実装の対応)

区間ごとに使う無線が違います。記事もこの通りに書いてあります。

| 区間 | 方式 | 対応する実装 |
| --- | --- | --- |
| リモコン → ESP32① | 赤外線 | `firmware/color_memory_game_ble`(受信部) |
| ESP32① → PC | Bluetooth(BLE) | `firmware/color_memory_game_ble` |
| PC ⇄ ESP32②(ガチャ側) | WiFi(HTTP + mDNS) | `firmware/gacha_lock_wifi` |

ガチャ側は当初BLEでしたが、電波が弱いと接続が切れて「排出した」の通知を取りこぼす問題が
実イベントで出たため、ポーリングで追いつけるWiFi(`/status` を0.4秒ごとに取得)へ移行しました。
記事のセクション09・12はこの経緯をそのまま説明の題材にしています。

ガチャ本体のロック機構(3Dプリンタ設計)は共同制作者による設計です。

※ページ内には来場者向けのソースコード公開リンクは置いていません(公開の導線は付けない方針)。

## 構成

素のHTML + CSS(フレームワークなし、ビルド不要)。`index.html` を開くだけで表示できます。

```
opencampus/
├── index.html
├── style.css
├── images/             写真(分解写真・配線写真など)
│   └── sensors/         スターターキットのパーツ紹介用の写真
├── videos/             デモ動画(demo.mp4 を置く)
├── POSTER_PROMPT.md    ガチャ機の横に貼るA4ポスターの生成プロンプト
└── README.md
```

図はすべてインラインSVGで自作しています。狭い画面では文字が読めなくなるため、
`.diagram-scroll` で囲んで **700px以下では縮小を止めて横スクロール**に切り替えています。
