# センサー工作の技術解説ページ

100円ショップの300円リモコンライトを分解して赤外線センサーを取り出し、そこから
**マイコン2台とPCをつないで、ゲームで目標スコアを取るとガチャガチャのロックが開く**
仕組みを作るまでを、一連の技術記事としてまとめた1ページのサイトです。
展示ブースの前でスマホから読める前提で作っています。

## 内容

1. 100円ショップで見つけた「300円のセンサー」
2. 分解してみると、こうなっていた(注釈つき写真)
3. ここをマイコンにつなぐと、受信できる(配線図)
4. 実際に受信してみる:シリアルモニタと受信コードの対応表
5. そもそも、ESP32ってなに?
6. **ここから本題:ゲームでガチャのロックを開ける(全体構成図)**
7. **ロックの正体は「サーボモーター」(PWMで角度を伝える仕組み)**
8. **「開けろ」をどうやって伝えるか(BLEのキャラクタリスティック)**
9. **「カプセルが出た」をどう確かめるか(反射型IRセンサー / 受信専用との違い)**
10. **いちばん面白いところ:状態を管理する(ステートマシン・誤検知対策)**
11. 赤外線・WiFi・Bluetoothの使い分け
12. アンケート
13. (おまけ)他にもこんなセンサーがある
14. (おまけ)まとめ

工作そのものの全ソースコード・配線・詰まったところの記録は別リポジトリで公開しています:
[sensor_infrared](https://github.com/KeitoKuramochi/sensor_infrared)

ガチャ本体のロック機構(3Dプリンタ設計)は
[MaedaReno/gacha-machine](https://github.com/MaedaReno/gacha-machine) によるものです。

## 構成

素のHTML + CSS(フレームワークなし、ビルド不要)。`index.html` を開くだけで表示できます。

```
opencampus/
├── index.html
├── style.css
├── images/             写真(分解写真・配線写真など)
│   └── sensors/         スターターキットのパーツ紹介用の写真
└── README.md
```

図はすべてインラインSVGで自作しています。狭い画面では文字が読めなくなるため、
`.diagram-scroll` で囲んで **700px以下では縮小を止めて横スクロール**に切り替えています。
